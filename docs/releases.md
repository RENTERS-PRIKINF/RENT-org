## Дополнительные пояснения

- **Release vs Version**: «Version» — это зафиксированный набор файлов (тег в Git); «Release» — запись о публикации этой версии на канале `main`.
- **Источник данных**: таблица собрана по коммитам и PR, видимым в репозитории на 2026-10-20. При добавлении новых тегов страницу нужно обновлять.
- **Каналы**: если в будущем появятся preview-ветки (например, `dev`), их история релизов может отображаться отдельно, без возможности отката.
