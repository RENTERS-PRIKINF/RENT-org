# Отчёт о покрытии программного кода тестами

**Проект:** RENT-org  
**Модуль:** backend  
**Инструмент измерения покрытия:** JaCoCo 0.8.14  
**Дата прогона:** 01.11.2026

## 1. Цель проверки

Цель проверки — измерить покрытие исходного кода backend автоматизированными тестами и проверить выполнение требования NFR-M-2: покрытие критически важной бизнес-логики unit-тестами должно составлять не менее 70%.

## 2. Средства и команда запуска

Для сборки и запуска тестов использовался Maven Wrapper. Измерение покрытия выполнялось JaCoCo версии 0.8.14.

Проверка запускалась из каталога `backend` командой:

```cmd
.\mvnw.cmd clean verify
```

## 4. Отчёт JaCoCo

Подробные метрики покрытия представлены в HTML-отчёте JaCoCo, который приложен к данному отчёту в каталоге `jacoco/`.

Главная страница отчёта:

[`jacoco/index.html`](jacoco/index.html)

HTML-отчёт содержит сводные показатели покрытия, разбивку по пакетам и классам, а также детализацию покрытия исходного кода. Для корректного отображения и работы навигации необходимо сохранять весь каталог `jacoco/`, включая `jacoco-resources` и вложенные HTML-файлы.

## 5. Вывод

Проверка backend-проекта RENT-org выполнена успешно: все 34 теста завершились без ошибок и пропусков.

Результаты измерения покрытия, в том числе показатели для критически важного сервиса `FlatService`, приведены в приложенном HTML-отчёте JaCoCo. По этим данным можно проверить выполнение требования NFR-M-2 для реализованной и протестированной бизнес-логики.

Измерение покрытия рекомендуется повторять при изменении бизнес-логики и добавлении новых критически важных модулей.
