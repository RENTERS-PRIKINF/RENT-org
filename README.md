# RENT

Репозиторий для командного проекта.

## О проекте

Тема: Разработка веб-приложения для учета недвижимости арендодателей.

Назначение: информационная система учета недвижимости предназначена для взаимодействия двух сторон: арендодателя и арендатора. Для арендодателя система решает проблему разрозненного учета и позволяет собственнику контролировать бизнес в одном окне. Для арендатора система предоставляет удобный личный кабинет, позволяющий самостоятельно вносить показания счетчиков, подавать заявки и оперативно получать уведомления
